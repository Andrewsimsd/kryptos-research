# Keyword-alphabet conventions, correction 3

This document registers `KEYWORD-ALPHABETS-0003`. The candidate family and K4
answer are unchanged from [amendment 2](keyword-alphabet-conventions-v2.md).
This correction fixes two descriptions of the experiment and moves the
independent calibration check before K4 evaluation.

## What is unchanged

The experiment still tests 39 decimal primers, 12 keyword-derived plaintext
orders, 12 keyword-derived ciphertext orders, and 26 relative rotations:

```text
39 × 12 × 12 × 26 = 146,016 models
146,016 × 24 known-letter equations = 3,504,384 K4 equations
```

The same immutable K4 input, request, model indexing, transformations, and
Python verifier are used. This correction is unblinded because the zero-survivor
answer was already known.

## Correct calibration language

Each planted case is constructed from a known candidate ID. The 24 known
plaintext positions recover a *set* of compatible IDs. The test then finds the
known true ID in that set, reconstructs its model, decrypts all 97 letters, and
reencrypts them. Therefore:

- 144/144 true IDs retained proves that the signature search does not discard
  the planted model;
- 144/144 known-true-model round trips test the forward and inverse transforms;
- 98/144 singleton sets are blind identifications from the 24-letter signature;
  and
- the other 46 cases are ambiguous and are not blind full-key recoveries.

Random A–Z planted messages are useful transformation tests. They are not a
calibration of a language-scoring attack. Future language attacks require
held-out plausible-language messages and selection without access to the true
candidate ID.

## Pre-search independent gate

The Rust calibration is now independently regenerated by Python immediately
after it is produced. K4 evaluation does not start unless that check succeeds.
The evaluator still regenerates and compares the calibration internally before
testing K4. This duplication is intentional defense in depth and is counted.

## Executed operation accounting

The primary unit is one crib equation or one transformed message position.
Amendment 2 reported the logical work represented in its final verifier output,
but omitted the evaluator's second complete calibration pass from the
coordinator's execution total. The actual registered total is:

| Executed work | Operations |
| --- | ---: |
| Produced calibration: signature census and planted transforms | 3,546,288 |
| Evaluator's internal complete calibration regeneration | 3,546,288 |
| K4 equations | 3,504,384 |
| **Total** | **10,596,960** |

These are scientific comparison/transform units, not processor instructions.
Builds, JSON handling, Python verification after K4, and regression commands
are outside this count and remain bounded by the wall-time cap.

## Interpretation

The result is an exact exclusion of this finite keyword/primer family only.
The correction does not turn 144 known-answer round trips into 144 blind
recoveries, and it does not identify a K4 plaintext, key, or historical method.
